# La caja fuerte de Karla

Web romántica estática preparada para GitHub Pages y móvil.

## Añadir las fotos

Copia las cuatro fotografías dentro de la carpeta `img` con estos nombres exactos:

- `Karla-1.jpg`
- `Karla-2.jpg`
- `Karla-3.jpg`
- `Karla-4.jpg`

En GitHub los nombres distinguen mayúsculas y minúsculas. Si tus fotos están en formato HEIC (habitual en iPhone), expórtalas antes como JPG.

## Publicar en GitHub Pages

1. Sube todos los archivos a un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main`, la carpeta `/ (root)` y pulsa **Save**.

GitHub mostrará la dirección pública cuando termine de publicar.
